False Positive Analysis (FP)

Example FP Scenario: Model predicts PRODUCT_DEFECT but physical inspection outcome is No Fault Found.

Root Cause of Error: Customer return text contained words like "doesn't work" or "stopped", causing text classifier to infer defect despite product testing 100% functional.

System Mitigation: Post-inspection evidence validator flags conflicting evidence and sends case to manual review queue.

False Negative Analysis (FN)

Example FN Scenario: Model predicts CUSTOMER_ORDER_ERROR but actual issue is recurring battery batch hardware failure.

Root Cause of Error: Customer selected ambiguous category "changed mind" or provided vague description.

System Mitigation: SKU anomaly detection engine detects return volume spike (>2.5x baseline) and generates P1 alert regardless of text classification.
